Google Fonts, vendored so frames render offline and deterministically: Bricolage Grotesque, Inter,
JetBrains Mono, Instrument Serif, Caveat (latin subsets, WOFF2). They are licensed under the SIL Open Font
License 1.1, not this repository's MIT license: [OFL.txt](OFL.txt) holds the license and each family's
copyright notice, and must travel with the files (`new_project.sh` copies it into every project's `build/fonts/`).

Swap freely; keep `fonts.css` in sync, preload new faces in `studio.html`, and add a new face's copyright notice
and license to this directory.
