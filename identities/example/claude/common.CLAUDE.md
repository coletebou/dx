# Example identity: rules for every Claude Code session of this identity

install.sh writes `~/.claude/CLAUDE.md` as an `@`-import stub that loads the
universal rules (`base/claude/CLAUDE.base.md`) and then this file, so the rules
here add to or refine those. Put what is true of you on every machine: your
repos and where they live, your conventions, the tools you use.

- My code lives in `~/code/<repo>`.
- Ask before pushing to a shared branch.
